Two rules firing is not confirmation

Independent alerts feel like corroboration. If both read the same field from the same source, they are one observation wearing two hats.

Two alerts on the same host in the same minute feel like proof. Sometimes they are. Often they are one fact counted twice.

Detections corroborate only if they observe different things. Two rules that both read the process command line from the same endpoint agent are reading one observation. If that field was wrong, truncated, or supplied by somebody who chose what it said, both rules are wrong in the same direction at the same time.

The uncomfortable part is that shared-input failures produce the most convincing alerts you will see. Two independent-looking detections agreeing is the pattern analysts are trained to trust.

What actually counts as independent is telemetry from different vantage points. The endpoint saw a process start, the network saw a connection, the identity provider issued a token. Those can disagree, and when they agree they mean something.

So when you group alerts for an analyst, group by entity but show the source. Two alerts from one source is a weaker position than two alerts from two, and the queue should make that visible rather than leave it to be worked out.

Take a pair of rules that often fire together. Write down the fields each one reads. If the lists overlap completely, they are one detection.

CHECK YOURSELF

Two separate detections fire on the same host within a minute and an analyst treats the pair as strong evidence. When is that reasoning wrong?

SHOW THE ANSWER

When both rules read the same field from the same log source

Why. Corroboration requires independence, and two rules sharing an input are not independent: one bad parse, one spoofed value or one broken field makes both wrong together, in exactly the way that feels most convincing. Shared authorship and shared technique mapping say nothing about whether the underlying observations are independent. Differing false positive rates are useful for weighing each alert on its own, and two rules can have very different rates and still fail together when the field they both trust is wrong.
