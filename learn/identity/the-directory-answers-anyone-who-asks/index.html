The directory answers anyone who asks

Authenticated users can read most of Active Directory by design, so one ordinary password is enough to map an entire organization.

Active Directory is a database that every authenticated user can read. That is not a misconfiguration. Applications, workstations and people need to resolve names, find printers and look up colleagues, so read access is the default for any account that can log in.

The consequence is that one ordinary account is enough to enumerate the whole organization. Every user, every group and its members, every computer, every organizational unit, the description fields somebody filled in years ago, and the service accounts with a principal name set.

None of that needs elevation. It needs a password.

This is why the first hour of an intrusion so often produces a complete map of an environment, and why “they must have had administrative rights” is usually the wrong conclusion. They had a user.

It also means your directory is a document you are publishing internally. Descriptions, comments and custom attributes are readable by everyone who can sign in, including the contractor account somebody created in 2019 and never got round to removing.

Sign in as a plain user with no special rights and read the description field on every service account. Whatever you can see there, so can anybody else who has a password.

CHECK YOURSELF

An intruder holding one standard user's password has mapped your group structure, service accounts and organizational units within minutes. What does that tell you about their privilege level?

SHOW THE ANSWER

Nothing beyond holding a valid account, because authenticated users can read the directory by default

Why. Read access for authenticated users is the default, not a misconfiguration, because workstations and applications need to resolve names and find resources. So fast and thorough enumeration is evidence of a working password and nothing more. The other three options all describe additional privilege, and assuming any of them sends an investigation looking for an escalation that never happened. That matters during triage: the reflex conclusion that they must have had administrative rights is usually wrong.
