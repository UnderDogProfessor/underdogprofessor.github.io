A signed token is not a secret

A JWT is signed so you can trust it has not been altered. It is not encrypted, so anyone holding it reads every claim inside.

Decode a JSON Web Token and you can read it. All of it. The claims are base64, which is an encoding rather than a cipher, and everything in there is visible to whoever holds the token.

The signature does one job. It proves the content has not changed since the issuer signed it. Integrity, not confidentiality, and the format deliberately provides one of the two.

This trips people in both directions.

Developers put things in claims that should not travel: internal identifiers, email addresses, role names that describe how the system is built, occasionally something worse. Every one of those is readable by the browser holding the token, by anything that logs the token, and by anyone who obtains it later.

Reviewers go the other way and treat a signed token as tamper-proof in every sense, which it is, while forgetting that reading it costs nothing at all.

Encrypted variants do exist. JWE wraps the payload so holders cannot read it, and most deployments do not use it, because the common case only needs integrity.

Take one token your own application issues. Decode it locally and read every claim. Then ask whether you would be comfortable seeing that content sitting in a log file.

CHECK YOURSELF

A review finds an internal employee number inside a JWT issued to a browser. The team argues it is safe because the token is signed. What is wrong with that reasoning?

SHOW THE ANSWER

Signing proves the claims were not altered, and does nothing to stop anyone reading them

Why. A signature provides integrity, not confidentiality. The payload is base64-encoded rather than encrypted, so anyone holding the token reads it with no key at all. The first option misstates what is signed, which is the header and payload together. The second confuses signing with encryption: a public key verifies a signature, it does not decrypt, and here there is nothing to decrypt. Hashing the value would genuinely help, which makes it a fix rather than a reason the current state is safe, and the question asks about the reasoning rather than the remedy.
